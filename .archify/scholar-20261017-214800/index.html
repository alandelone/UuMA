如何在 Observatory 中查看 Scholar

01找到 Scholar 卡片

默认配置入口：127.0.0.1:8790。收起态显示研究层级摘要与文献处理概览。此链接只表示配置入口，本次未启动或验证该服务。

02点击卡片，展开四块详情

研究层级（Field → Topic → Track / Thread → 稿件）；文献六阶段流水线；FieldKG 与 Snapshot；研发阶段及改动。点击同时打开右侧 Scholar Inspector。

03用活动流查看发生了什么

按 Scholar 筛选活动，点击事件查看时间、工具和来源载荷。卡片的数据模型与活动流来自两条读取链，活动到达不代表科研卡片已重新读取。
