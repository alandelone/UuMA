# Artifact Readiness

Before forming an artifact, restore state and checkpoint meaningful pending changes. Check:

- PRD: problem, users, scope, requirements, success criteria, unresolved risks.
- Architecture: ownership, boundaries, interfaces, state, flow, security, failures, tradeoffs.
- SOP: trigger, actors, preconditions, steps, decisions, exceptions, outputs, recovery.
- Implementation plan: deliverables, dependencies, sequence, acceptance, rollout, rollback.

Return concrete missing fields when the target is not ready. Build from accepted state and label
unresolved assumptions rather than silently deciding them.
