# Discussion Checkpoint

Create a checkpoint transaction at topic switches, session pauses, handoffs, build transitions, and
meaningful maturity changes. Include current understanding, accepted decisions, assumptions, open
questions, rejected directions, tension, sources, and the next useful step. Do not create a milestone
checkpoint for every decision.
