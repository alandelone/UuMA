# Scholar owned preview maintenance

Before replacing a preview, confirm its exact root, command, parent chain, listener ownership, original database digest and absence of queued/running model jobs. Use an exclusive backup directory for each attempt; preserve any earlier backup and failed log. Keep a consistent SQLite backup and verify all original rows and schema objects across declared migrations.

Windows hidden Python launchers can have a conhost.exe console companion in addition to the actual Python server child. Record the companion only after its exact Windows System32 executable path and parent are verified. Keep it separate from backend processes selected for replacement; listener ownership must still resolve to the verified backend chain. Unknown descendants remain a refusal. Recheck each target immediately before replacement and wait briefly for the verified listeners to close.
