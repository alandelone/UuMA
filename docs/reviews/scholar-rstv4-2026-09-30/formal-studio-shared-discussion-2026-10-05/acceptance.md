### 统一讨论流程

```mermaid
flowchart LR
    Catalog[Catalog 论文／内容] --> Fixed[固定来源及原文版本]
    FieldKG[选定 Field 的图谱／来源] --> Fixed
    Track[Track 研究内容] --> Fixed
    Studio[Studio 原作者结构／成文对象] --> Fixed
    Overview[Field／Topic／Track 全局列表] --> FieldKG
    Overview --> Track
    Fixed --> Draft[问题／精确选区／讨论批注]
    Draft --> Compare[新选择时明确比较]
    Compare --> Draft
    Draft --> Annotation[单独保存批注并保留问题]
    Draft --> Request[保存原请求及选定父链]
    Request --> Model[真实模型讨论]
    Model --> Receipt[实际回复／错误及原调用]
    Receipt --> Followup[继续所选讨论或开始新讨论]
    Followup --> Draft
    Receipt --> Suggestion[Studio 分型建议]
    Suggestion --> Decide[作者明确完整／部分采用或拒绝]
    Decide --> History[修改历史及来源]
```

全局 Field／Topic／Track 列表继续作为独立导航入口；FieldKG 展示选定 Field 的图谱。本图说明本批讨论接入关系，不代表 Collection、完整科学知识图谱或全 pipeline 已通过。
