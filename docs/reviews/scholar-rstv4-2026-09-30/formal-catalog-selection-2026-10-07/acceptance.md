## 本批接通

从真实 Topic／Track 打开既有采集页，可以按题名、DOI／作者搜索 Catalog，分页勾选已有论文，查看／移除本次选择，再检查实际 PDF 完整性并开始采集。

选入使用真实 paper ID，无 DOI 的已登记论文也可选；与相同 DOI／BibTeX 的输入合并为一个采集成员，原始输入继续保存，原 DOI-only 请求重试格式保持。

选入先按本次范围筛选，之后才处理文件。文件身份待审／目录隔离继续等待复核；已有完整已验证文件复用原 file version 并进入解析队列。
本批软件 HTTP 流程没有实际执行解析、QuickRead、Skeleton 或科学评审，不能据此关闭完整 pipeline。
