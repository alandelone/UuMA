## 保留的失败与修正

1. 首轮新夹具漏 defer 的必需参数；旧页面测试仍要求未接入原型。按实际接口与 AC-06 修正，初始无真实归属时仍禁用开始，失败日志保留。
2. Python 日期样式检查发现冗余 Z 替换，使用原生解析；规则没有禁用。
3. 首次全库缺 DSPy；隔离环境仅继承 base 环境后又缺 pypdf／docx。保留两次加载失败，安装完整已声明依赖后全库通过，没有假模块或新增 skip。
4. 旧启动 helper 限定 8885 与旧根目录，不能拿来启动新 8886 软件资料；首次 0 请求失败保留，使用专门的根目录／端口校验 helper。
5. 后台服务继承输出管道导致首个捕获 helper 等待 EOF；只关闭已验证且暂停的资料服务，再用文件记录后台启动输出。没有停止共享服务。
6. 一次严格字节断言遇到夹具未关闭连接的 WAL 时机问题。显式关闭全部夹具连接，逻辑／物理相等断言保持；原失败工具输出保留，没有伪造文件日志。
7. 直接 PowerShell 文件启动被本机策略拒绝，执行前停止；沿用普通已允许的内联命令，没有改执行策略或 Chrome 权限。
