# Yonc Telegram 操作手册与指令指南

记录日期：2026-10-29，Asia/Kuala_Lumpur。

为 Yonc 加入专用的 Telegram 快捷操作手册与问答引导，方便随时查看项目概况、发起目标拆解、分配专家协同及审计变更回执。

## 已加入的入口

在 Yonc 的 Telegram 私聊中输入 `/yonc`，查看目录和例子（可直接点击对应命令链接执行）：

| 入口 | 内容定位 |
| --- | --- |
| `/yonc_split`（或 `/yonc split`） | 目标拆解与规划：实时从项目图谱按 Deadline / Timeline 由近到远排序，标注层级编号（如 `1.1`、`1.2`、`2.1`），支持直接带编号查询（如 `/yonc_split 1.1`）或关键词过滤，提供一键复制拆解口语例句 |
| `/yonc_projects`（或 `/yonc projects`） | 真实项目库总览：按 6 大核心领域划分，标注组号与编号（如 `1.1`、`2.1`），支持输入组号展开全组（如 `/yonc_projects 1`）或单项详情（如 `/yonc_projects 1.2`）以及关键词检索 |
| `/yonc_assign`（或 `/yonc assign`） | 专家分发与指派：Brainstormer/Scholar/Forge/honc 协同建议 |
| `/yonc_history`（或 `/yonc history`） | 变更审计与回执：实时拉取最近 3 次图谱 Commit 批次，提供回执核对引导 |
| `/yonc_graph`（或 `/yonc graph`） | 了解图谱授权机制：草案规划、依赖校验与 Web UI 授权提交 |

手册与导航命令直接由本地命令处理，支持快速读取当前运行的 Yonc API / SQLite 数据库，无延迟且不消耗 LLM Token；不会越权进行写图谱操作或直接分发任务。
所有推荐例句均使用 Telegram 原生 Markdown 等宽代码格式包裹，在客户端中轻点文本即可自动复制进剪贴板，随后粘贴发送即可。
同时支持无空格的下划线直达指令（如 `/yonc_split_1_1` 或 `/yonc_projects_1`），在 Telegram 中呈现为蓝色可点击链接，点击可直接发送并展开对应详情。
原生 `/model`、`/new`、`/stop` 不变。

## 可以直接发送的典型例句（轻点即可复制）

- 目标拆解：`准备拆解 1.1〈Thesis Phd Logic〉，目标是两周内上线，先列出主要 Action。`
- 项目查询：`查询项目 3.1〈素食堂 菜单开发〉的上下文、子任务和完成标准。`
- 补充草案：`继续拆解任务〈任务ID〉，补充测试用例和异常流程。`
- 进度查询：`帮我列出目前正在进行中的 L3 重点项目和卡点。`
- 专家指派：`这项任务〈任务ID〉适合指派给哪个专家 Agent？评估一下工作量。`
- 回执核对：`核对一下今天从 honc 同步过来的完成回执。`
- 提交准备：`检查当前草案的依赖完整性，准备提交。`

## 机制与安全边界

1. **草稿隔离**：在 Telegram 上的所有拆解讨论与指派建议均保存在会话草稿中，不会直接修改正式图谱。
2. **双向命令兼容**：内部同时注册下划线与连字符形式（如 `yonc_split` 与 `yonc-split`），兼容 Telegram 网关归一化规则。
3. **安全提交**：最终图谱写入（Commit）必须通过受信 Web UI 获取单次有效授权码。
